1) Switch wifi from 2.4G to 5G / 5G to 2.4G
2) Check battery fuse, switch, and voltage
3) Check battery volatge under load (7v is threashold where the controll hub auto resets)

0) Left Motor (LM))
1) Right Rotor (RM)
